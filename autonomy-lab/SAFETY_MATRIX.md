# Simulation Safety Matrix

| Research layer | Purpose | Can close production qualification? |
|---|---|---|
| Source registry | Trace public US/EU/VN/international/OEM principles | No |
| Gap detector | Find under-researched domains | No |
| Independent oracle | Deterministic decision/degradation/rejection research | No |
| Parameter sweep | Explore boundary sensitivity and decision transitions | No |
| ASAM bridge | Prepare simulator-neutral export metadata | No |
| Virtual-to-physical map | Link virtual findings to HIL/track evidence IDs | No |
| Vietnam track pack | Define synthetic local research intent | No |
| HIL / target / closed-track evidence | Physical validation under controlled procedures | Only after actual execution and review |

The simulation score is intentionally isolated from the Gate-3 production qualification decision.

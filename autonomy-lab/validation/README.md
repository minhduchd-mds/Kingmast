# KINGMAST virtual-to-physical validation

Virtual safety research never closes a physical validation item by itself. `virtual-to-physical-map.json` only links research domains to the existing HIL and controlled-track evidence IDs so engineers know which physical evidence must follow a virtual finding.

`vietnam-controlled-track-pack.json` adds synthetic Vietnam-focused scenario intent for CT-001..CT-008. It contains no real coordinates and grants no test authorization. Every physical run still requires the protected evidence workflows, approved facility, frozen build/config/calibration identity, read-only vehicle boundary and independent review.

# KINGMAST v0.0.7 — Software release checkpoint

Date: 2026-09-09  
Status: development software checkpoint  
Safety authority: warning-only SAE Level 0; no steering, braking, throttle, gear, torque, drivetrain or CAN-write authority.

## Scope

v0.0.7 consolidates the Vietnamese HMI and KINGMAST Assistant V1 upgrade into one reviewable software checkpoint.

### HMI and localization
- Runtime locale support for `en-US` and `vi-VN`.
- Vietnamese coverage across startup, first-run, Drive, Navigation, route recovery, map fallback, alerts, EV/Trip/Object/Vehicle views, Settings, connectivity, privacy, driver profile and device diagnostics.
- First-run language selection for English / Tiếng Việt.
- Provider-authored road names, route instructions and external alert text remain source-authored when no trusted translation exists.
- The HMI keeps established `kingmast:v006:*` persisted-data keys for backward compatibility; those keys are schema identifiers, not the v0.0.7 product version.

### Assistant V1
- Server-side provider adapter; provider credentials are never exposed through `NEXT_PUBLIC_*` or browser code.
- Grounded read-only assistant planning through the risk-engine allowlist.
- Vietnamese natural-language and no-diacritic routing for vehicle/device, alert, road, navigation, charging, settings and help intents.
- Native voice bridge first, browser speech-recognition/TTS fallback for bench and supported browser hosts.
- Moving mode disables long text composition and keeps a compact voice-first interaction.
- Bounded transcript/message history in memory only; no assistant transcript persistence.
- Device metadata is bounded before provider use: maximum 16 devices and 8 faults per device, with raw video, coordinates and serial-number fields excluded.
- Deterministic grounded/offline fallback when provider or live context is unavailable.

### Safety and quality gates
- Assistant tool allowlist remains read-only.
- No actuator/function tool surface is provided to the external AI provider.
- External provider endpoint requires HTTPS except explicit loopback bench HTTP.
- UI safety contracts are localization-aware without weakening warning-only invariants.
- Tests cover Vietnamese/no-diacritic requests, prompt-injection attempts, moving-mode restrictions, offline device fault explanation and native Vietnamese voice bridge behavior.

## Compatibility

- API generations `/v3`, `/v4` and `/v5` are unchanged by this release number.
- Existing HMI localStorage namespaces are retained to avoid deleting preferences, route cache or first-run completion state during update.
- Existing provider/device/operator identity trust domains are unchanged.

## Evidence and qualification boundary

Historical evidence explicitly bound to `v0.0.6` or filenames containing `V006` remains a historical v0.0.6 record. This release does not rename those artifacts and does not claim that HIL, physical bench, closed-track, firmware trust, secure boot or public-road qualification has been re-run for v0.0.7.

A future v0.0.7 physical evidence campaign must create new version-bound artifacts and independent review records rather than relabel v0.0.6 evidence.

# Scenario catalogue
Required suites include stationary/slow/braking lead vehicle, cut-in/cut-out, curves, grade, motorcycles splitting lanes, fast rear approach/tailgating, neighboring-lane radar targets, rain/fog/night/glare/dirty sensors, CAN loss, timestamp skew, packet loss, ECU overtemperature and reboot.

Each scenario must pin software version, dataset/scenario version, expected severity window, allowed latency, sensor state and evidence location.
